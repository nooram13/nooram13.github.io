LEARNING TO CODE ♡

My Programming Experience

Programming was not completely new to me when I started studying at HZ because I had already learned some Python before.

However, JavaScript felt quite different from Python, especially the syntax. Because of that, I needed time and practice to become more comfortable with it.

What I Have Worked With

Python

Python was one of the first programming languages I learned. It helped me understand basic programming concepts such as variables, conditions, loops and functions.

JavaScript

At HZ I started working more with JavaScript. Its syntax feels different from Python, so I am still practising how to solve problems with it.

HTML & CSS

During PCO I learned more about building and styling websites using HTML and CSS. I used these skills to create this portfolio.

What I Find Challenging

One challenge for me is remembering the different JavaScript methods and understanding which one should be used in a certain situation.

Sometimes I understand the idea of a problem but still need time to turn that idea into working code.

I have also learned that making mistakes is part of programming. An error does not always mean that I do not understand the subject. Sometimes I only need to look at the problem in a different way.

Practice helps me improve. When I make mistakes, I try to understand what went wrong instead of only looking at the final answer.

My Programming Goal

I want to become more confident when writing code and improve my problem-solving skills.

I also want to understand programming well enough that I can build my own projects independently.

Because I am currently interested in Software Engineering and cybersecurity, improving my programming knowledge is especially important for my future.
